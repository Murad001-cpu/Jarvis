# JARVIS Səsli Köməkçi

# Giriş
JARVIS, Azərbaycan dilində danışan, səni eşidən və kameranla görən şəxsi səsli köməkçidir.

# İmkanlar
- **Səsli söhbət:** Azərbaycan dili əsasdır. Rus, ingilis, türk, fransız və alman dilləri də var.
- **Oyanış sözü:** "Jarvis oyan" deyəndə mikrofona toxunmadan cavab verir. F4 düyməsi mikrofonu açır.
- **Kamera:** "Bu nədir?" deyəndə kameradakı kadrı görüb cavab verir.
- **Video redaktor:** Videonu seçib əmrlər verə bilərsiniz (kəsmək, sürətləndirmək, filtr, yazı əlavə etmək, səsi silmək).
- **Hava və xəritə:** Yerləşdiyin şəhərin havası və xəritəsi.
- **Zaman idarəetməsi:** Zamanlayıcı (taymer), kronometr və xatırlatmalar.
- **Öz səsi:** İstəsən ElevenLabs ilə seçdiyin səslə danışır.

# Quraşdırma və İlk Başlanğıc
- **Kompüter:** Chrome və ya Edge-də "Brauzerdə aç" düyməsinə basın. Brauzer menyusundan səhifəni tətbiq kimi quraşdırın.
- **Android:** Chrome-da açın, menyudan "Ana ekrana əlavə et" seçin.
- **iPhone / iPad:** Safari-də açın, Paylaş düyməsindən "Ana ekrana əlavə et" seçin.
- **API Açarının Daxil edilməsi:** Giriş ekranında API açarını yapışdırın (Pulsuz Google Gemini açarını aistudio.google.com/apikey səhifəsindən ala bilərsiniz). Açar yalnız cihazın brauzerində saxlanılır.
