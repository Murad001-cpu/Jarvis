# JARVIS — Şəxsi Səsli Köməkçi

JARVIS, Azərbaycan dilində danışan, sizi eşidən və kameranızla görən şəxsi səsli köməkçidir.

## İmkanlar
- **Səsli söhbət:** Azərbaycan dili əsasdır. Rus, ingilis, türk, fransız və alman dilləri də dəstəklənir.
- **Oyanış sözü:** "Jarvis oyan" dedikdə mikrofona toxunmadan cavab verir.
- **Kamera:** "Bu nədir?" dedikdə kameradakı kadrı görüb cavab verir.
- **Video redaktor:** Videonu kəsmək, sürətləndirmək, filtr tətbiq etmək, yazı əlavə etmək və səsi silmək imkanı.
- **Hava və xəritə:** Olduğunuz şəhərin hava və xəritə məlumatlarını göstərir.
- **Zaman idarəetməsi:** Zamanlayıcı (taymer), kronometr və xatırlatmalar yaratmaq olar.
- **Öz səsi:** İstəyə görə ElevenLabs vasitəsilə seçdiyiniz səslə danışa bilir.
